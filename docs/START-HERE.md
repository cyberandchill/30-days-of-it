# Build a portfolio that proves your skills

A résumé tells employers what technologies you know. A project portfolio shows what you can do with them.

Use the [CyberAndChill Technical Portfolio](../README.md) as an example: concise architecture diagrams, working results, screenshots, and a manual walkthrough behind each build.

## How to structure each project

1. **Name the technical problem.** Example: centrally manage Windows logins.
2. **Show the architecture.** Keep the diagram simple enough to understand quickly.
3. **Explain what you implemented.** Focus on the actual environment and your decisions.
4. **Prove the result.** Include a relevant screenshot and a brief verification summary.
5. **Document the manual steps.** Give readers enough GUI detail to reproduce the outcome.
6. **Link the project on your résumé.** Direct a hiring manager to the specific build relevant to the role.

Keep private access details, credentials, internal infrastructure identifiers, and proprietary build workflows out of your public repository.
