# Build 30 for 30 — Start your own IT portfolio

Build and verify up to 30 IT projects. Each gets one clean architecture card, a **GUI-first walkthrough with a few real screenshots**, and deeper technical evidence for readers who want it.

You can fork or copy the public repository. The rendering workflow uses Python 3.10+ and the standard library. Infrastructure, Microsoft services and lab credentials are separate from the GitHub repo and must be authorized independently.

To publish a completed day with Codex:

> Review only the build and evidence from this day's conversation. Update my Build 30 for 30 repository: a clean high-level architecture card, a short outcome-focused project page, and a reproducible manual GUI walkthrough with exact clicks, choices and expected results. Place real sanitized screenshots beside relevant steps. Keep scripts, hashes and detailed logs in secondary evidence. Don't invent results, reveal private data or change unrelated days. Render, check, commit, push and verify.

Refer to `AGENTS.md` and `docs/WORKFLOW.md` for maintenance rules.
